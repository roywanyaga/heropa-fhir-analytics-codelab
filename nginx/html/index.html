FHIR analytics codelab

Your lab has three parts. Open each one in its own tab and keep them open.

EditorThe ViewDefinitions, the dashboard code, the guide and a terminal. It asks for the password your lab printed. DashboardThe Observable Framework dashboard. It reloads after each build. PipelinesThe FHIR Data Pipes controller. Run the pipeline from here.

Scan the QR code to open the dashboard on your phonePoint the camera of the phone at the code.

  1. Run the pipeline in the Pipelines tab, or with run-pipeline in the Editor terminal.
  2. Run refresh in the terminal to rebuild the dashboard from the new tables.
  3. Switch to the Dashboard tab. It reloads by itself.
