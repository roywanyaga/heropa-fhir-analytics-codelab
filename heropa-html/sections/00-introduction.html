Analytics on FHIR with FHIR Data Pipes and Observable Framework

This guide takes you through the analytics codelab on the Heropa lab. You look at FHIR data on a FHIR server, run the FHIR Data Pipes pipeline, and watch a dashboard built with Observable Framework fill with numbers. Then you change a ViewDefinition and add more data, and watch the dashboard follow. You install nothing.

It follows the same path as the published SQL on FHIR analytics tutorial, with the dashboard written in Observable Framework in place of Superset. This guide covers the lab only.

The synthetic data is made by a generator taken from the OHS Player analytics repository. It also contains the Sengmany family from the SMART Trust demonstrator, a fictional family whose child has vaccine doses recorded in two countries.
